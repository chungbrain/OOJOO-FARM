# Build 2026081001 개선사항

## 목표

Master와 Farmer 앱에서 기존 한글 고정 UI를 한국어와 영어 중 선택할 수 있도록 변경했습니다.

## 주요 변경

- Master와 Farmer 설정 화면에 한국어/English 선택 항목을 추가했습니다.
- 선택한 언어를 앱 전용 설정에 저장하고 화면 전체에 즉시 적용합니다.
- 앱을 강제 종료하거나 기기를 재부팅해도 마지막으로 선택한 언어를 유지합니다.
- 기존 설치에서 언어 설정이 없거나 시스템 언어를 사용하던 경우 한국어로 한 번만 마이그레이션합니다.
- 지원하지 않는 언어 값은 한국어로 안전하게 정규화합니다.
- Master 전체 화면과 Farmer 대시보드·페어링·설정·서비스 알림 문자열을 한국어/영어 리소스로 분리했습니다.
- Android 13 이상에서는 플랫폼 `LocaleManager`, 이전 버전에서는 AppCompat 로케일 API를 사용합니다.
- 두 APK의 버전 코드를 `2026081001`, 버전 이름을 `1.0.2026081001`로 갱신했습니다.

## 검증

- `node scripts/verify-locales.mjs`
- `:master:app:testDebugUnitTest`
- `:slave:app:testDebugUnitTest`
- `:master:app:assembleDebug`
- `:slave:app:assembleDebug`
- Android API 34 에뮬레이터에서 Master와 Farmer의 한국어 기본 표시를 확인했습니다.
- 두 앱에서 English를 실제로 선택한 뒤 화면이 즉시 영문으로 변경되는 것을 확인했습니다.
- 두 앱을 강제 종료·재실행한 뒤에도 영문 선택이 유지되는 것을 확인했습니다.

## 호환성

- Master 최소 Android 버전: API 26
- Farmer 최소 Android 버전: API 24
- 지원 언어: 한국어(`ko`), 영어(`en`)
