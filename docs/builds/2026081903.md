# Build 2026081903 개선사항

## 목표

Farmer가 방울토마토 이미지를 온디바이스 tiny CNN으로 분석해 건강 원인(건강, 물 부족/과다, 햇빛 부족, 해충, 고온)을 판별하고, 물 부족이면 관수·해충이면 바람을 자동으로 켜게 했습니다.

## 주요 변경

- 식물별 독립 모델 포맷 `OJP1` 과 추론기 `PlantHealthNet` 을 Farmer에 추가했습니다. 가중치 파일은 약 수십 KB 수준입니다.
- 방울토마토 전용 모델 `assets/models/cherry_tomato.bin` 을 학습해 넣었습니다. 입력 48×48, conv8-16-24 + GAP + 6-class. 검증 정확도 약 81%.
- 학습 데이터는 방울토마토 잎·열매 색과 형태를 반영한 조건별 사진(클래스당 80장)입니다. 클래스는 `healthy`, `water_low`, `water_high`, `light_low`, `pest`, `heat` 입니다.
- 식물의 `species` 가 방울토마토/토마토이면 이 모델을 쓰고, 없으면 기존 색상 휴리스틱으로 폴백합니다.
- 모델이 `water_low` 이면 자동 관수, `pest` 이면 Fan을 켭니다.
- 학습 스크립트: `ml/plant_health/train.py`
- 버전: `1.0.2026081903` (`versionCode` 2026081903)
