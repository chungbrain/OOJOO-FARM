# Build 20260819001 개선사항

## 목표

Master에서 가족·친구를 초대해 Farmer와 식물을 공동 소유하고 함께 조작할 수 있게 했습니다.

## 주요 변경

- 백엔드에 `households`, `household_members`, `household_invites` 테이블과 `/api/household` API를 추가했습니다.
- 주인은 6자리 초대 코드를 만들고(이메일은 선택), 가족·친구는 로그인 후 코드로 같은 농장에 참여합니다.
- `GET /api/pairing/:userId`, `GET /api/plants/:userId`, `GET /api/notifications/:userId` 가 같은 가구 멤버의 Farmer·식물·알림을 함께 반환합니다.
- 가구 멤버는 공유된 Farmer를 관수·팬·레이저·카메라 등으로 조작할 수 있습니다.
- Master 설정(계정)과 Farmer 목록에서 "가족 · 친구" 화면으로 들어갈 수 있습니다.
- 공유된 Farmer/식물 카드에 공유 배지를 표시합니다.
- 두 APK의 버전 이름을 `1.0.20260819001` 로 갱신했습니다. Android `versionCode` 는 32비트 Int 한도 때문에 `2026081901` 입니다.

## 검증

- `node --experimental-sqlite --test` (`가구 초대: 가족/친구가 Farmer·식물을 공동 소유` 포함)
- `node scripts/verify-locales.mjs`
- `:master:app:assembleDebug`
- `:slave:app:assembleDebug`

## 호환성

- Master 최소 Android 버전: API 26
- Farmer 최소 Android 버전: API 24
- 백엔드: 기존 SQLite DB에 가구 테이블이 자동 생성됩니다. 혼자 쓰는 계정은 이전과 같이 본인 리소스만 보입니다.
