# Build 2026112015 개선사항

## 목표

실기기 설치 후 master 앱이 서버에 접속하지 못하는 문제 해결:

- 사용자가 입력한 `34.50.20.236:4000`은 잘못된 IP (2026-08-27 작업 일지에
  기록된 오타 주소). GCP VM의 실제 고정 IP는 **`34.50.40.104`**.
- 기본 설정(`server_config.yaml`)이 에뮬레이터 전용 `10.0.2.2`로 되어 있어
  실기기에서는 첫 실행 기본값으로 접속 불가.

온보딩/설정에서 `http://10.0.2.2:4000/`로 수동 전환.
