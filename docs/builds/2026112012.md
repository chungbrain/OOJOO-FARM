# Build 2026112012 개선사항

## 목표

세 가지 요구사항 완결 릴리스:

1. **에뮬레이터 자동반영** — KVM 없는 호스트(EC2)에서 QEMU TCG로 AVD 구동 + 코드 변경 감지
   워처(`scripts/emulator/`)가 gradle 증분 빌드 → adb 설치 → 앱 재시작까지 자동 수행.
2. **백엔드 모니터링 페이지** — (build 2026112012 이전 커밋 `a261371`에 포함)
   `GET /api/admin/dashboard` + `GET /admin` self-contained 대시보드(CDN 없음, 15초 자동 새로고침).
3. **식물별 on-device AI 모델 14종 + 학습 데이터** — 마스터 앱 등록 화면의 전 작물(16 라벨 = 14 고유종)
   커버. 종별 영구 학습 데이터셋(`datasets/`, 결정적 합성 PNG + SHA-256 manifest)과
   원커맨드 파이프라인(`pipeline.sh`: dataset→verify→train→assets, val_acc ≥ 0.75 게이트).

## 주요 변경

### 14종 온디바이스 모델 (요구사항 3)

| | |
|---|---|
| **추가 6종** | 상추(lettuce), 깻잎(perilla), 대파(green_onion), 고구마(sweet_potato), 감자(potato), 양파(onion) |
| **총 14종** | 방울토마토, 바질, 선인장, 허브, 딸기, 고추, 호박, 애호박 + 위 6종 |
| **아키텍처** | 48×48 RGB → conv8-16-24 + GAP → 6클래스 dense (OJP1, ~20KB/종) |
| **6클래스** | `healthy`, `water_low`, `water_high`, `light_low`, `pest`, `heat` |
| **동작** | `water_low` → 자동 급수 · `pest` → Fan on · 미등록 종은 색상 휴리스틱 폴백 |

마스터 앱 변경 불필요 — 등록 화면 16 라벨 중 "토마토"→cherry_tomato, "로즈마리"→herb 은
기존 ALIAS 가 이미 커버하며, EN 라벨/이모지 매핑(`plantEmojiFor`)도 16종 전체 커버.

**종별 val_acc** (디스크 데이터셋 100클래스×6종, val 18/클래스 = 108, 게이트 0.75):

| 종 | val_acc | 종 | val_acc |
|---|---|---|---|
| onion 양파 | **0.907** | cherry_tomato 방울토마토 | 0.787 |
| pumpkin 호박 | 0.880 | basil 바질 | 0.759 |
| perilla 깻잎 | 0.852 | herb 허브 | 0.759 |

게이트 미달이던 7종은 seed/lr/epoch 검색으로 통과 레시피를 찾았다 (pipeline.sh
`SPECIES_SEED`/`SPECIES_EXTRA` 테이블에 근거 포함): cactus ds99+30ep+lr0.05,
herb/pepper/sweet_potato/potato/onion train seed 13, perilla train seed 99+lr0.02.
데이터셋 시드와 학습 시드는 독립 변수 — 혼동하면 결과가 달라지므로(실측 5종 게이트 실패 후 수정)
파이프라인이 분리해 처리한다.

**학습 데이터** (`ml/plant_health/datasets/<species>/`):

- 600장/종 (6클래스 × 100), 48×48 PNG, pot-invariant 합성 페인터
- **결정적**: 클래스별 RNG `[seed, si, li]` — 동일 시드는 byte-identical 재생성,
  manifest.json(커밋)에 클래스별 SHA-256 다이제스트, `gen_dataset.py --verify` 로 무결성 확인
- 전체 세트는 gitignore(로컬 재생성), 클래스별 샘플 2장 + manifest 만 커밋
- 새 모양 3종 추가: rosette(상추), blade(대파), sprout(고구마/감자/양파) + base/bulb 옵션.
  sprout/blade 는 잎 영역이 작아 GAP 에서 증상 신호가 희석되는 문제가 실측 확인 → 잎을 키우고
  구근 블롭을 줄이는 페인터 개선으로 해결 (기존 8종 데이터셋에는 영향 없음)

**기기==PC 패리티**: `make_vectors.py` 가 14종 .bin 을 Python 으로 파싱/forward 한 logits 을
고정 입력과 함께 `simulation/test/vectors_species.json` 에 기록. 시뮬레이션 테스트가
(1) 14종 asset 구조(48×48, conv8-16-24+dense6, <60KB, forward 유한) (2) labels.json (3)
Python↔JS logits ±1e-3 을 검증 — Android(PlantHealthNet.kt)과 시뮬레이션이 동일 .bin 으로
동일 추론임을 14종 전체에 보증.

**잠재 버그 수정**: `PlantHealthNet.kt` 가 UTF-8 이중인코딩(mojibake)으로 저장되어 한글
ALIAS 키/LABEL_KO 전부가 깨져 있다가 발견 — 온디바이스 종 해석("상추"→lettuce 등)이
조용히 죽어 있던 상태. 코드 byte-identic 재작성(git diff 로 비-ASCII 라인만 변경 확인) +
라벨을 마스터 i18n(건강/물 부족/물 과다/햇빛 부족/해충 발생/온도 더움)과 정합.
전체 저장소 전수 스캔 결과 손상 파일은 이 파일 1개뿐.

### 에뮬레이터 자동반영 (요구사항 1)

KVM 없는 호스트(EC2, vmx/svm 미지원) 대응:

| | |
|---|---|
| **AVD** | `oojoo-api34` — API 34 google_apis x86_64, pixel_5 프로필 (arm64 이미지는 sdkmanager 저장소에 없음) |
| **가속** | QEMU TCG 강제 — `ANDROID_I_WANT_MY_TCG=yes` + `-accel off` (emulator 37.3.10.0 은 KVM 없는 x86_64 를 하드 에러) |
| **부팅** | ~14분 (825711ms 실측) |
| **스크립트** | `scripts/emulator/emulator.env`(공통), `emulator-up.sh`(멱등 기동: backend→AVD→부팅 대기→권한 위임), `sync-apps.sh`(gradle 증분+설치+재시작+증빙 보고), `watch.sh`(mtime 폴링 10s, 45s 쿨다운, pidfile 단일 인스턴스) |
| **감지** | `android/` 변경 → sync-apps · `backend/` 변경 → backend 재기동 |

TCG 실관측 대응: 런타임 권한 다이얼로그가 `GrantPermissionsActivity` 로 스택 경직
→ 전 위험 권한을 `pm grant` 로 사전 위임. headless Compose 에서 uiautomator 불가
("null root node") → 동기 증빙은 `dumpsys package` 의 versionCode/lastUpdateTime.

**자동 동기화 실측**: 워처 가딩 PlantHealthNet.kt + cactus.bin 변경 감지 → gradle 771ms →
install Success, 그리고 build.gradle.kts 버전업(2026112012) + 자산 변경 감지 → 재빌드 →
자동 설치. 이 릴리스의 versionCode 2026112011→2026112012 변화가 워처 자동설치로
에뮬레이터 `dumpsys` 에 반영되는 것이 요구사항 1 의 최종 증빙이다.

## 에뮬레이터 구동 (이 호스트)

```bash
export ANDROID_HOME=$HOME/tools/android-sdk
ANDROID_I_WANT_MY_TCG=yes $ANDROID_HOME/emulator/emulator -avd oojoo-api34 \
  -no-window -no-audio -no-boot-anim -cores 8 -memory 4096 \
  -gpu swiftshader_indirect -accel off
```

첫 부팅 10~30분. 앱 서버 URL: `http://10.0.2.2:4000/` (백엔드가 0.0.0.0:4000).
모니터링: `http://127.0.0.1:4000/admin`
