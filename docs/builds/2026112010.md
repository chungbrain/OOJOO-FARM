# Build 2026112010 개선사항

## 목표

Farmer(슬레이브)의 안전/신뢰성 결함을 정리하고, 마스터 UI·백엔드·ML·문서의 미진한 부분을 마무리한 릴리스입니다.
특히 **자동 관수 범람(시간당 약 36L) 위험**과 **BLE 오프라인 시 거짓 "관수 완료" 보고**를 수정했습니다.

## 주요 변경

### Farmer(슬레이브) 안전·신뢰성
- **자동 관수 범람 수정**: 직전 분석의 `needWater` 가 true 로 유지되는 동안 30초 틱마다 밸브를 다시 열던
  level-triggered 동작을, 상승 엣지(false→true) + 30분 재관수 쿨다운으로 변경.
  수동/마스터 지시 관수에도 쿨다운 기준점 갱신(겹침 방지).
- **BLE 오프라인 거짓 관수 수정**: ESP32 미연결 시 밸브가 실제로 열리지 않으면 `water_failed`
  이벤트를 보고(기존엔 "관수 완료" 로 기록). 하드웨어 연결 상태가 `watering` 성공 판정에 반영.
- **BLE 자동 재연결**: 연결 단절 5초 후 재연결, 스캔 15초 타임아웃 재스캔, 중복 스캔 가드, GATT 정리.
  명시적 `disconnect()` 만 재연결을 취소.
- **오프라인 큐 race 수정**: `enqueue`/`flushQueue` 의 read-modify-write 를 Mutex 로 직렬화
  (충동 flush 와 동시 적재 시 기록이 사라지던 lost update 방지).
- **명령 완료 보고 정확화**: water/capture_photo/capture_video/diagnose_video 가 실제 작업
  완료(또는 실패) 후에야 `done` 으로 보고. 즉시 `done` 이던 fire-and-forget 처리 수정.
- **정책 반영**: `capture_interval`(10분~6시간) · `pest_interval`(5~120분) 이 실제로 주기 캡처/해충 대응
  쿨다운을 제어(이전엔 저장만 되고 동작에 미반영).
- **식물별 관수 귀속**: ROI(다중 식물) 루프에서 물을 필요로 하는 해당 식물을 관수하고
  해당 식물에 이벤트/로그를 귀속.
- **배터리 부족 알림**: 20% 이하 하락 엣지에서 `battery_low` 이벤트(1시간 쿨다운).

### 마스터 앱
- 홈 대시보드를 실제 분석 데이터로 교체(가짜 습도/조도/demo 식물 제거).
- Farmer 화면: 6개 필드 정책 편집(관수/Fan/Laser + 캡처·해충 주기 + ROI), 별명 변경, 명령 이력.
- 식물 상세: 수확 기록(수량/단위/메모/날짜) 저장+이력, 정밀 mL 표시의 즉시 관수 확인.
- 1:1 쪽지(DM) 대화 목록+스레드, 프로필 편집, 알림 deep-link, "모두 읽음".
- 무한 스피너 대신 에러+재시도(리포트/마켓/커뮤니티).
- 라이브 카메라 사진 모드 상태·체크아웃 실패 메시지 i18n 보정.
- 미사용 온보딩 라우트·스크린, 8.3MB GLB 자산(plant/robot), SpeechBubble 삭제(APK 경량화).
