# Build 20260819002 개선사항

## 목표

작물이 수확·나눔에 이르기까지 쌓인 사진으로, Master에서 한 번 누르면 Farmer가 아주 짧은 성장 스토리 숏클립(시간·위치 + BGM)을 만들게 했습니다.

## 주요 변경

- Farmer는 카메라가 켜져 있을 때 하루에 한 장, 또는 식물이 눈에 띄게 변하면 사진을 로컬 앨범에 저장하고 서버로 보냅니다.
- 백엔드에 `plant_photos` 테이블과 `/api/photos` API를 추가했습니다. Master 식물 상세에서 누적 사진첩을 봅니다.
- Master의 **숏클립만들기** 는 `generate_growth_clip` 명령을 Farmer에 보냅니다. 클립 합성은 Farmer가 합니다.
- Farmer는 사진에 촬영 시각·위치를 겹치고, 생성한 펜타토닉 BGM(AAC)을 섞어 짧은 MP4를 올린 뒤 Master가 바로 재생합니다.
- `videos` 테이블에 `plant_id`, `kind=growth`, `photo_count` 를 추가했습니다.
- 두 APK 버전 이름: `1.0.20260819002` (`versionCode` 는 32비트 한도로 `2026081902`).

## 검증

- `node --experimental-sqlite --test` (성장 사진첩 업로드/조회 포함)
- `node scripts/verify-locales.mjs`
- `:master:app:assembleDebug`
- `:slave:app:assembleDebug`

## 호환성

- Master 최소 Android 버전: API 26
- Farmer 최소 Android 버전: API 24
- Farmer 대시보드(카메라 바인딩)가 켜져 있어야 사진 촬영과 숏클립 렌더가 됩니다.
