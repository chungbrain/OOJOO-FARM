# Build 2026081906 개선사항

## 목표

Farmer 온디바이스 건강 진단에 허브 전용 tiny CNN을 추가했습니다. 물 부족이면 관수하고, 해충이면 Fan을 켭니다.

## 주요 변경

- `assets/models/herb.bin` 허브 독립 모델을 학습해 넣었습니다.
- 클래스는 healthy, water_low, water_high, light_low, pest, heat 입니다.
- 검증 정확도 약 58%. 입력 48x48, conv8-16-24 + GAP + dense6.
- 식물의 species가 허브이면 이 모델을 사용합니다.
- 버전: `1.0.2026081906` (versionCode 2026081906)

## 검증

- `py -3 train.py --species herb` val_acc=0.5833333333333334
- `:slave:app:assembleDebug` / `:master:app:assembleDebug`
