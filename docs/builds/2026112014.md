# Build 2026112014 개선사항

## 목표

4건 + 1건(추가 요청)의 신규 요구사항:

1. **W1 — 홈 "나의 농장"에서 farmer(로봇)가 부드럽게 움직이도록**
2. **W2 — 식물 이동 시 UI 문제 발견/수정**
3. **W3 — 식물 팻말, 로봇 디자인 개선**
4. **W4 — 날씨 분리: 좌측상단 = farmer(농장) 날씨(메인), 우측상단 = master(사용자)
   날씨(작게), 날씨 그래픽은 farmer 기준으로 유지**
5. **W5 — 설정에서 "내 날씨 함께 표시" 옵션화** (사용자 추가 요청)

## 주요 변경

### 1. farmer 위치 보고 (W4 데이터 파이프라인)

| 계층 | 구현 |
|---|---|
| **backend** | `slaves.lat/lon/region` 신규 컬럼(ensureColumn). 하트비트가 동적 컬럼 builder로 리팩토링(기존 battery/stream 4갈래 분기 대신). 좌표는 `num()`으로 검증 — **`Number(null)===0` 함정 회피**(null/빈 문자열/비숫자 거부) + ±90/±180 범위, region 1..100자. 무효/미보고 시 기존값 유지 |
| **slave** | 신규 `LocationUtil` — last-known GPS/network/passive(30분 신선도) + 8초 한도 single-update, 그래도 없으면 오래된 last-known 사용(농장은 움직이지 않으므로), **IP 폴백 없음**(헤드리스 부담 방지). 30분 날씨 루프에서 해석, `fetchWeather`도 좌표가 있으면 좌표 기반. 하트비트에 lat/lon/region 보고. manifest `ACCESS_FINE/COARSE_LOCATION`(BLE maxSdk-30 FINE 줄 대체 — BLE 31+는 BLUETOOTH_SCAN/CONNECT 사용), MainActivity 런타임 요청(거부 시 region 기반 폴백) |
| **master** | `Slave` 모델에 lat/lon/region. `pickFarmerWeather()`: online+GPS 좌표 있는 farmer 우선 → `weatherByCoords`, 없으면 region → `weather(region)`, 둘 다 없으면 null(사용자 날씨 폴백 = 과거 동작) |

테스트: backend 86→**87** (저장/목록 반환/무효 4종/미보고 유지/경계값).

### 2. 홈 날씨 분리 + 설정 옵션 (W4 UI, W5)

- **좌측상단**: 🏡 농장 태그 + 메인 날씨(40sp 온도). `weather = farmerWeather ?: userWeather` —
  **하늘/비/밤 씬 그래픽도 이(=farmer) 기준**.
- **우측상단**: 사용자 날씨 소형 칩(📍 나 + 온도 + WMO 이모지), 씬 ☀️ 아래(top 54dp).
  **farmer 위치 확보 상태에서만 표시** — 폴백 상태(메인==사용자)에서 같은 데이터 두 번
  보여주는 것을 방지.
- **설정(기어) → "홈 옵션"** → "내 날씨 함께 표시" Switch — `Prefs.showUserWeather`,
  기본 **ON**(원래 요구=표시 유지, 끄는 것만 옵션). ON_RESUME 리프레시의 재구성 시 반영.

### 3. 농장 씬 (W1/W2/W3)

`FarmSceneView`(2D 이모지 씬) 3개 영역 재작성:

| | 과거 | 현재 |
|---|---|---|
| **로봇 이동** | `robotX.animateTo` → `robotY.animateTo` = L자 경로, 코너 급정, 고정 400ms | X/Y **동시 tween(직선)**, 시간 = 260ms + 320ms/cell (0.3~1.5s 캡), 이동 방향으로 **회전**(scaleX ±1), 이동 중 **기울기** ±4° |
| **순찰 인덱스** | `LaunchedEffect(waypoints)` 재기동마다 idx=0 리셋 — 식물 이동/목록 변화마다 첫 식물로 점프 | 인덱스 `remember` 유지 — 웨이포인트 변화 시 **그 자리에서 재개**, 목표 식물이 이동하면 새 위치로 부드럽게 접근 |
| **식물 위치** | `plantCells`가 **리스트 인덱스 키** — 추가/재정렬 시 전 식물 재배치(랜덤) | **식물 ID 키**(`cellMap`) — 순서 무관 안정, 새 식물은 결정적으로 빈 cell 배정(중심 기준, 동일행 간격), 삭제 시 cell 해제 |
| **드롭 충돌** | 점유 cell에 겹침 | 점유 시 **드롭점에서 가장 가까운 빈 cell**로, 빈 cell 없으면 **원위치** |
| **드롭 애니메이션** | 즉각 텔레포트 | ~180ms tween(`animateFloatAsState` — 드래그 위치에서 새 cell로), 취소 시 부드럽게 복귀 |
| **팻말** | 흰 직사각형 60dp, 줄기 x=28dp(중앙 아님), 최하단 행은 카드 하단으로 **잘림** | **나무 팻말** — 세로 그라디언트+어두운 테두리, 고정 64dp **정중앙 배치**, 줄기 중앙, 미세 경사(±2.5°), 긴 이름 **줄임표시**, 최하단 행은 **원 위쪽으로 플립**(클립 방지) |
| **로봇 디자인** | 🤖 이모지 1개 | **primitives 조립** — 안테나(봉+황색 불빛), 헤드(스틸 그라디언트 + **3.4초 주기 깜빡이는 눈**), 몸통(녹색 그라디언트 + 화면), 바퀴 2개, 관수 중 **아래로 떨어지는 물방울** 3개(떨어질수록 투명) |

`plantEmojiFor`와 `FarmSceneView` 시그니처는 불변(타 화면 5곳이 plantEmojiFor 사용).

## Compose 1.6.8 API 실측 (이 빌드에서 확인)

- `keyframes` 블록의 receiver는 `KeyframesSpecConfig` — 지속시간 프로퍼티는
  **`durationMillis`** (구식 `durationMs` 아님). 클래스 파일 javap으로 확인.
- `animateFloatAsState`는 **`androidx.compose.animation.core`** 패키지
  (`androidx.compose.runtime` 아님 — MainActivity 기존 import로 확인).
- `Modifier.offset { }` (람다, 측정 크기 기반) 오버로드는 이 버전 foundation에 없음 —
  팻말은 고정 크기(64×24dp)로 산술 중심 정렬로 대체.
