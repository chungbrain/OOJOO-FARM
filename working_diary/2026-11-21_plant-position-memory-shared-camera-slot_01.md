## ① 식물 위치 기억 (`FilamentViewer.kt`, `Prefs.kt`)

**기존 문제:** `cellMap`이 `remember` 상태로만 관리돼 앱 재시작(프로세스 종료)마다 자동 배치(`pickEmptyCell`)로 초기화 — 옮겨둔 위치가 사라짐.

**구현:**

- `Prefs` 신규 저장소 — `farmPlantCells`: `plantId → "row,col"` JSON 오브젝트
  - `farmPlantCells()` 읽기, `setFarmPlantCell()` 개별 저장, `removeFarmPlantCells()` 삭제 정리
- `FarmSceneView`:
  - 초기 `cellMap`을 저장소에서 복원 — 마지막으로 옮겨둔 위치가 첫 프레임부터 반영
  - 드래그 드롭(`onDragEnd`)에서 `target != cell`일 때 저장소에 즉시 저장
  - `LaunchedEffect(cells)`에서 배치 전체 동기화 — 새 식물 자동 배정 위치 저장 + 삭제된 식물의 저장 위치 정리
  - 기존 충돌 회피 규칙(점유 cell → 가장 가까운 빈 cell)·재배치 애니메이션은 그대로 유지

동작: 식물을 꾹 눌러 드래그 → 새 cell에 드롭 → 즉시 저장 → 앱 재시작 후에도 그 자리에 배치.

## ② 통합 미디어 슬롯 (`LiveCameraScreen.kt`)

**기존 문제:** 사진 카드(상단) → 3초 영상 카드(중간) → 실시간 스트림 카드(하단)가 Column에 **순서대로 누적** — 라이브를 켜면 3초 영상 아래 별도 위치에 라이브 화면이 생겨 화면이 계속 밀려남.

**구현:**

- 세 콘텐츠가 **하나의 슬롯**(같은 위치, 280dp 카드)을 우선순위로 공유:
  `liveFrame > videoInfo(3초 영상) > photoUrl > 대기`
- 실시간 보기 중이면 라이브 프레임이 **3초 영상이 보이던 바로 그 자리**를 차지 (LIVE 배지·3초 갱신 안내 포함), 종료하면 직전 결과(3초 영상/사진)로 같은 자리에 복귀
- 라이브 연결 진행/에러 표시는 슬롯 위 상단으로 이동 — 연결 중에도 직전 결과가 슬롯에 유지돼 화면이 흔들리지 않음
- `request()`(사진·영상 촬영) 시작 시 라이브 자동 종료(`stopLive()`) — 같은 슬롯에서 촬영 흐름으로 자연 전환, farmer의 push 루프도 즉시 정리
- 촬영 모드별 버튼(재촬영/사진/갤러리/실시간/뒤로)은 슬롯 아래 컨텐츠에 맞춰 표시 — 기존 구성 유지
