# 웹 사진 추가학습 후 재평가

Openverse / Wikimedia / iNaturalist에서 CC 사진 **452장**을 모았습니다. 이 중 **360장은 추가학습**, **90장은 학습에 쓰지 않은 테스트**입니다. 검색 엔진 크롤링은 하지 않았습니다.

## 결과

같은 held-out 테스트 90장 기준입니다.

| | 일치율 |
|---|---:|
| 추가학습 전 (합성만) | **15.6%** |
| 웹 사진 추가학습 후 | **23.3%** |

절대 수준은 아직 낮습니다. 다만 이전에 거의 0이던 `healthy`가 바질·고추·애호박에서 보이기 시작했습니다.

## 데이터

- 출처: Openverse(CC), Wikimedia Commons, iNaturalist(CC)
- 라벨: 검색어 기반 약한 라벨
- 식물당 대략 50~60장, 클래스 균형은 healthy/pest/water_high/light_low 각 80장, water_low 74, heat 58
- 학습 때 합성 잎 이미지와 웹 사진을 섞어 기존 온디바이스 가중치를 파인튜닝했습니다.

## 한계

- 6클래스 무작위는 16.7%입니다. 23%는 그보다 조금 높을 뿐입니다.
- 검색어 `wilted tomato`와 실제 물 부족이 같지 않아 라벨 잡음이 큽니다.
- `pest`와 `heat`는 여전히 거의 맞추지 못합니다.
- 방울토마토는 추가학습 후 오히려 떨어졌습니다. 약한 라벨이 합성으로 배운 단서를 흐린 것으로 보입니다.
